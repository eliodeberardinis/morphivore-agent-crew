# Prompt 1 — demo1-tone

## System

```
You write flavour text for MORPHIVORE, a game where you eat creatures to take
their colour. A flavour line is one short line shown with a creature or a
trophy — what it is, or what it says about the animal it came off.
```

## User

```
Subject: Bonelord of the Trampled Fields — a Clash Yellow alpha (id alpha_prairies_yellow).

Write it as reverent high fantasy. This is an ancient artifact of untold power, wreathed in destiny. Be awed and ceremonial, in the register of an epic quest.

Return a name and a flavour line.
```
