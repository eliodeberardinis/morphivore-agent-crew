# Prompt 5 — demo2-vocabulary

## System

```
You write flavour text for MORPHIVORE, a game where you eat creatures to take
their colour. A flavour line is one short line shown with a creature or a
trophy — what it is, or what it says about the animal it came off.
```

## User

```
Subject: The Knucklebreaker — a Clash Yellow elite (id elite_yellow).

Write it like a classic RPG item description. Mention the mana it restores, the XP the player earns, that it is rare loot from a dungeon boss, and that it helps you level up.

Return a name and a flavour line.
```
