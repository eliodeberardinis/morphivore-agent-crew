3.3 Engine integration — the Unity MCP bridge

AI output becomes running gameplay through a **custom Unity Editor plugin** (`MCPBridge.cs` / `MCPBridgeWindow.cs`) on a local socket — no external network — exposing commands (`write_file`, `refresh_assets`, `play`, `get_components`).
