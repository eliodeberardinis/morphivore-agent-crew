# Prompt 9 — demo3-formatting

## System

```
You write flavour text for MORPHIVORE, a game where you eat creatures to take
their colour. A flavour line is one short line shown with a creature or a
trophy — what it is, or what it says about the animal it came off.
```

## User

```
Subject: Scrawny Thumper — a Pale Yellow prey (id prey_yellow_pale).

Write an enthusiastic, detailed description of at least four sentences. Use exclamation marks. Tell the player directly what they should do with it and why they will love it.

Return a name and a flavour line.
```
